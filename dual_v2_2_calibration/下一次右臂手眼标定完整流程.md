### 5.1 主动标定的两阶段流程

新的轨迹生成器不是均匀撒点。它先从一小批已验证姿态估计固定的
`T_ee_board`，再在真实 `dual_v2_2` 右臂模型上生成候选，并依次执行：

1. 取 CuRobo 限位与运行时 `armR` 软限位的交集，再保留 `5°` 裕量；
2. 过滤端点自碰撞；
3. 将 `T_base_ee · T_ee_board` 投影到相机，过滤出界、过小和倾角过大的棋盘；
4. 将每个视角的棋盘六自由度位姿作为干扰变量，用 Schur 补得到只针对
   `fx, fy, cx, cy, k1, k2, p1, p2, k3` 的 Fisher 信息；
5. 用 D-optimal Next-Best-View、画面覆盖、姿态多样性和运动距离联合选点；
6. 对最终轨迹按 `2°` 关节步长检查整段插值自碰撞。

先用已经人工确认安全且能看到棋盘的轨迹采集一个 seed 会话，并完成一次
粗内参和粗手眼外参。seed 至少需要 10 个有效且有旋转变化的样本：

```bash
/mnt/ssd/robotarm/env/robotram_wx/bin/python \
  camera_calibration_cv/example/record_data_on_right_hand.py \
  --targets camera_calibration_cv/example/calib_demo.txt \
  --dry-run
/mnt/ssd/robotarm/env/robotram_wx/bin/python \
  camera_calibration_cv/example/record_data_on_right_hand.py \
  --targets camera_calibration_cv/example/calib_demo.txt \
  --execute
/mnt/ssd/robotarm/env/robotram_wx/bin/python \
  camera_calibration_cv/example/calibrate_intrinsics.py \
  --minimum-views 10
/mnt/ssd/robotarm/env/robotram_wx/bin/python \
  camera_calibration_cv/example/calibrate_extrinsics.py \
  --minimum-poses 10
```

seed 只用于建立粗几何关系，不作为最终结果。然后运行：

```bash
cd /mnt/ssd/user/wx/vlm_demo
/home/vlmdemo/miniconda3/bin/conda run -n curobo --no-capture-output \
  python camera_calibration_cv/example/generate_active_intrinsic_poses.py \
  --config camera_calibration_cv/config.yaml \
  --seed-session /mnt/ssd/user/wx/vlm_demo/calibration/<seed会话> \
  --num-samples 16384 \
  --num-views 64 \
  --output calibration/active_intrinsic_targets.txt \
  --report calibration/active_intrinsic_plan.json
```

该命令只生成文件，绝不会向机器人发送命令。报告中的
`fully_visible_and_informative`、每个视角的 `information_gain`、
`joint_limit_margin` 和 `board_mount_estimation` 必须先人工检查。

把 `camera_calibration_cv/config.yaml` 的 `calibration_path` 改为新的最终会话，

/mnt/ssd/robotarm/env/robotram_wx/bin/python \
  camera_calibration_cv/example/record_data_on_right_hand.py \
  --targets calibration/active_intrinsic_targets.txt \

采集脚本会同步保存：

```text
calibration/<新会话>/results/
├── 01.png
├── ...
├── joint_position.csv
├── ee_pose.csv
└── records.csv
```

每个目标必须同时满足实际关节位置、插值目标和速度阈值；到位后等待 `0.8 s`，
再从 5 帧同步图像/机器人状态中优先选择能识别棋盘且 Laplacian 清晰度最高的一帧。
`records.csv` 会保存该帧的 `sharpness`。

采集后确认：

- PNG 数量与 CSV 数据行数量一致；
- `joint_position.csv` 保存的是右臂数据；
- `ee_pose.csv` 格式为 `x,y,z,qw,qx,qy,qz`；
- 机器人位姿具有充分的平移和旋转变化；
- 不存在运动中拍摄、棋盘丢失或明显模糊的样本。

## 7. 先标定内参，再标定手眼外参

先独立计算并保存相机内参。这个阶段只读取棋盘格图像，不依赖
`ee_pose.csv`：

```bash
cd /mnt/ssd/user/wx/vlm_demo
/mnt/ssd/robotarm/env/robotram_wx/bin/python \
  camera_calibration_cv/example/calibrate_intrinsics.py
```

确认 `intrinsics.yaml` 的焦距、主点、畸变和重投影误差合理后，固定该
内参并计算手眼外参：

```bash
/mnt/ssd/robotarm/env/robotram_wx/bin/python \
  camera_calibration_cv/example/calibrate_extrinsics.py
```

输出目录：

```text
calibration/<新会话>/base_to_camera/results/
├── intrinsics.yaml
├── intrinsics_report.json
├── extrinsics.yaml
├── machine-readable results.json
└── report.json
```

如果内参来自另一个独立会话，第二步显式指定文件：

```bash
/mnt/ssd/robotarm/env/robotram_wx/bin/python \
  camera_calibration_cv/example/calibrate_extrinsics.py \
  --intrinsics /绝对路径/intrinsics.yaml
```

建议检查：

- 内参有效样本数不少于 50；
- 手眼外参有效同步姿态不少于 30；
- `intrinsics_report.json` 的 `quality_pass` 为 `true`；
- 内参的 held-out 中位 RMS 重投影误差低于 `0.5 px`；
- 内参 Fisher 信息的 `observable_rank` 为 9；
- 焦距相对标准差低于 `1%`；
- `report.json` 的 `quality_pass` 为 `true`；
- Tsai、Park、Horaud、Andreff、Daniilidis 的结果接近；
- 方法间旋转差异尽量小于 `1°`；
- 方法间平移差异尽量控制在 `10–15 mm` 内。

系统不再固定使用 Daniilidis，而是计算五种方法，并选择“棋盘安装变换在所有
样本中最一致”的方法。选择指标和五种结果都保存在
`hand_eye_method_selection` 中。
