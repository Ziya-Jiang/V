# cart_book_grasp_v3

V3 复用 V2 双视角 SAM3/GPT 选书和原有抓放动作，在 **J7 调整、Y 对齐及原深度回退补偿完成后，X 前伸开始前** 插入手腕图像闭环。V2 文件和启动方式不变。

本版控制机器人**基座 Y/Z**，固定基座 X 和工具姿态。J7 仍由 V2 的三维书脊逻辑处理；沿 X 的前伸距离仍由头部深度计算。它是“规划路点 → 等待完成 → 采集新图像”的分步伺服，尚不是连续六自由度 IBVS，也不在插入书页期间横向纠偏。

## 图像雅可比

参考用户提供的 [Robot Academy — The Image Jacobian](https://robotacademy.net.au/lesson/the-image-jacobian/) 文字稿：点特征的 2×6 雅可比把相机坐标系的平移/旋转速度映射成像素速度，平移项涉及相机深度。`point_image_jacobian` 实现这个针孔相机公式，并以数值投影差分测试其六个方向。

当前手腕相机没有内参和手眼标定，实际执行使用它在基座 Y/Z 控制方向上的**局部实测等效雅可比**：

```text
delta_uv = J_base_yz * [delta_base_Y_mm, delta_base_Z_mm]
delta_yz = -gain * J.T * inv(J*J.T + damping^2*I) * (uv - uv_reference)
```

每轮在当前深度和姿态分别探测 Y−、Y+、Z−、Z+，每个探测后回到伺服起点；默认每次 2 mm。拟合使用实际 TCP 位移，包含轴间耦合，不用命令位移替代实测值。所有探测和修正都走原规划器。端点共线或固定 X 不代表规划器中间路径严格直线。

GPT 只负责选书和跨视角匹配。伺服从匹配的手腕 mask 内提取 SIFT 纹理，用双向匹配和 RANSAC 单应性跟踪固定的 mask 中心点；不每轮重新调用 GPT，不把邻近书自动替换为目标。该点定义为初始所选手腕 mask 的 x/y 像素中位数，随纹理变换跟踪，不是不断重分割后跳动的中心。

## 首次运行：登记正确对齐时的参考

**不能猜参考像素，也不能默认使用图像中心。** 相机偏置、夹爪安装姿态和观察距离决定了正确对齐时目标应落在哪个像素。`cart_book_grasp_v3_servo.json` 的 `reference` 初始为 `null`；未登记时启动即报错，尚未初始化机器人。

1. 用已有人工控制方法，将夹爪放到已验证的正确对准、尚未前伸的参考姿态，保留书前自由空间。此工具不会替你移动到参考姿态。
2. 记录右 TCP 的基座 X 与工具 Euler XYZ 角度（度），以及头部检测的书表面基座 X；`surface_gap_mm = book_surface_x_mm - TCP_base_X_mm`。这里不是相机光轴深度，也不是指尖到书的距离。默认要求这个差值至少 100 mm。
3. 在该姿态采集手腕图像，取得所选书本 mask 中心的参考像素 U/V。可仅拍照，随后用图像查看器读取坐标；不要把相机画面上的左右直接转成机器人 Y。

```bash
1``

4. 使用实测数值登记参考。下面是参数格式，`U V GAP RX RY RZ` 都需要替换为你的实测数字，不是可直接执行的样例数值。

```text
python cart_book_grasp_v3.py --set-reference U V --surface-gap-mm GAP --tool-euler-deg RX RY RZ
```

该命令仅写配置，不连接机器人；同时记录 V2 双视角配置里的手腕设备路径和分辨率。运行时要求相机、分辨率、观察距离及工具方向与参考相符，默认距离误差 ≤10 mm、方向误差 ≤3°。大幅改变 J7、相机安装位置或观察距离后应重新建立参考；当前版本没有用未知手眼关系猜测新的目标像素。设备路径相同无法检测相机被物理重新安装，重新安装后必须重教。

```bash
python cart_book_grasp_v3.py --check-config
python cart_book_grasp_v3.py --assume-head-camera-calibrated
```

V3 复用 V2 的 GPT 配置、密钥环境、SAM3、双视角相机配置；运行前关闭占用手腕设备的预览程序。首次实机验证仍需检查参考是否正确，离线测试不能验证夹爪真实对齐关系。

## 执行顺序与参数

1. 输入选书文字；右臂 first_reset；头部/手腕采集，SAM3 候选、GPT 跨视角选书。
2. 沿用 V2 目标几何检查、J7 调整、基座 Y 粗对齐和已有 Z 回退补偿。
3. 手腕重新定位同一本书；校验参考距离/姿态；必要时 4 次局部探测并回起点，估计雅可比。
4. 小步修正基座 Y/Z；误差连续 2 帧 ≤3 px 才允许前伸。若开始已经满足条件，不探测、不纠偏。
5. 沿用 V2 动态 X 前伸、合爪、抬升、停顿期间反转已记录 J7、分段下降、松爪、抽回、first_reset。

`cart_book_grasp_v3_servo.json` 每次伺服开始时热加载一次，动作中不切换参数或参考。默认单步 2 mm、总偏移半径 20 mm、累计命令路径预算 80 mm（包含探测）、最多 15 次纠偏、总时限 180 秒。目标丢失、图像重复/过期、雅可比退化、误差连续增大、实际 TCP 未到位、预算超限都会终止本轮；**不静默回退到 V2 前伸**。这些位置限制约束观察点和命令端点，不代替规划器的整段路径碰撞检查。

`cart_book_grasp_v3_config.json` 和 `cart_book_grasp_v3_wrist_config.json` 是独立的动作参数副本。保留建立 V3 时的 V2 数值，包括伸入 100 mm、抬升 200 mm、下降 150 mm，不自动改回早期的参数。

失败后沿用 V2 等待回车重试；`p` 沿用中断、松爪、first_reset；`s` 沿用停止后续任务。`p` 是经规划器处理的操作中断，不是硬件急停。

## 可视化与记录

Rerun 原 `Wrist RGB / GPT review` 面板在伺服期间显示新帧：黄色是跟踪点，绿色是参考点，箭头是像素误差；只用英文标注。纠偏路点通过原路径显示器记录。

每轮记录到 `RobotRAM/output/v3_servo_<unique_id>/`：逐帧叠加图、`events.jsonl`（观测点、基座 Y/Z、雅可比、纠偏命令、退出原因与本轮配置）。未收敛的日志不会标成抓取完成。

离线测试：

```bash
python -m unittest test_cart_book_grasp_v3 -v
```

测试涵盖相机/基座方向符号、轴间耦合、实测位移拟合、解析矩阵数值投影、收敛与发散、旧帧、丢失跟踪、操作中断、规划失败，以及伺服失败不能进入 V2 前伸。保存的真实手腕图片还可验证纹理跟踪；合成图像平移的通过不代表已完成实机闭环测试。
