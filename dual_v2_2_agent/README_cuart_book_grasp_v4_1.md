## 原按键和循环

- `s`：本轮结束后退出，不再启动下一轮。与 V3.4 一样，不是急停。
- `p`：原协作中断 → 保持 → 松爪 → 右臂 first_reset → 等待回车继续。
- 失败：保持当前夹爪指令，等待回车重试或 `s` 退出。
- 成功：确认抽回完成后保持闭指和当前位置，等待回车开始下一轮（先first_reset再感知）。不再自动等待5秒重启。等待时p复位、s退出仍有效；运动期间提前按回车不会排队触发下一轮。V3.4/V1_3默认成功自动循环不变。

## 实际动作

每轮先复用感知前 `first_reset`，随后通过原 `close_gripper` 动作闭指，再采集头部图像。SAM3 书脊优先、旋转检出和 GPT 备用均来自 V3.4。

从同一次选定的书脊掩膜提取上端中心，读取附近真实深度；书脊中心沿用原感知结果；前伸使用本轮整书掩膜内有效深度点反投影并转换后的基座 X 中位数。取所有有效点转换后的X中位数，不直接使用相机Z中位数。当前没有另起一次独立 GPT 选书，也没有旧 V4.1 的三帧散布、整面平面、独立速度/采样间隔检查。

执行时把原抓取任务替换为：

1. 仅 Y 对齐书脊中心。
2. 仅 Z 抬升：offset = 书上沿 Z − 当前名义手指 Z + 110 mm。
3. 仅 X 前移：offset = 整书有效实测点基座 X 中位数 + 100 mm − 指尖相对TCP的基座X偏移 − 当前 TCP X。指尖偏移由当前保持姿态旋转工具向量 `[0,0,-50]` mm 得到，不直接固定减50mm。
4. 仅 Z 下降：以本阶段最新实测TCP为起点，固定offset = −50 mm，不按上沿高度重算终点。
5. 仅沿基座−X抽回70mm：从下降后的最新实测TCP计算，保持Y/Z和原姿态，保持闭指；确认到位后等待回车。

例如上沿高于当前手指100mm，则抬升210mm；前移后从实测位置固定下降50mm，名义结束在上沿上方60mm。日志`V4.1 相对位移`显示本段实测起点、offset和转换后下发TCP；原planner需要绝对TCP，因此仅在每段动作生成时做相加转换。Rerun整段预览仅为名义示意，不作为后续动作缓存目标。

每个阶段从最新实测 TCP 计算保持轴，沿用配置中的 TCP 到手指偏移和第一阶段姿态。粗动作每段最多 50 mm，下降每段最多 10 mm，到位使用原反馈检查接口的 3 mm / 1° 和连续新鲜反馈。

自定义普通动作名 `book_v41_top_*` 避开原抓取动作的自动开爪、J7 预对齐、100 mm 插入及抓取后抬升/松爪抽回。它们通过原 step5 执行器和普通 CuRobo 规划，不进入腕部视觉伺服。

原基础模块可能仍打印原抓取流程介绍或生成原始 9 步草案；执行前会明确打印 `V4.1 实际任务` 并替换为上述 5 阶段，Rerun 的目标预览和已发目标使用上沿动作。

## 配置与证据边界

动作距离单独放在 `cuart_book_grasp_v4_1_distances.json`，单位均为mm：

```json
{
  "hover_above_top_mm": 110.0,
  "forward_insertion_mm": 100.0,
  "final_z_offset_from_top_mm": null,
  "lower_offset_mm": -50.0,
  "withdraw_mm": 70.0,
  "coarse_step_mm": 50.0,
  "descent_step_mm": 10.0
}
```

- `hover_above_top_mm`：抬到上沿上方的净空。
- `forward_insertion_mm`：书X中位数后的伸入量，仍扣除指尖X偏移。
- `final_z_offset_from_top_mm`：下降结束时名义指尖相对上沿高度；0为齐平，正数在上方，负数在下方。
- `lower_offset_mm`：固定相对下降模式；当前-50表示从实测起点下降50mm。当上沿终点字段为null时使用此值。
- `withdraw_mm`：下降后沿基座−X抽回的距离，正数，当前70mm；纳入总路径预算及原到位检查。
- `coarse_step_mm` / `descent_step_mm`：粗动作/下降分段上限。

启动新版程序后，每次Y对齐、抬升、前伸、下降、抽回开始前重新读取并校验整个距离文件。保存后下一个阶段生效；正在执行阶段的参数快照锁定，不中途改写其分段轨迹。当前阶段已完成的轴不会因修改其他参数而重新移动。终端`V4.1 距离参数已热加载`及Rerun `book/v41_distances`记录该阶段实际参数；预览读取最新文件，仅供参考。文件缺失、JSON不完整、字段错误或超范围时，在新阶段发运动指令前报错，沿用原失败保持流程。

主文件 `cuart_book_grasp_v4_1_config.json` 只通过 `distance_config` 指向距离文件，相对路径按主文件所在目录解析。工具偏移、到位容差和总行程限制留在主文件，不参与距离热加载。下降范围上限150mm覆盖110mm净空及反馈偏差；范围上限不是指令下降量。`cart_book_grasp_v3_config.json` 继续管理原复位J6。旧独立流程的几何散布、速度观察等字段不再参与本入口感知。

首次加载本次代码仍需重启抓取程序，此后仅改距离JSON无需重启。原planner和V3.4配置不变。

V3.4 原感知仍保留其 SAM3 书脊判定、同书整书掩膜、有效深度和 GPT 备用的原条件；没有宣称这些检查全部删除。新增上沿采样质量不足只记录质量，完全无有效深度则无法形成三维目标。上端来自选定书脊掩膜，遮挡或误分割仍可能导致上沿位置误差。

只验证了离线接线、任务顺序、单轴目标、分段、失败和中断传播、原执行器不自动开爪以及共享回退链路；尚未实机验证这版搭接动作。位置到位不代表已经接触书，也不代表接触力已确认。


## 上沿显示

重启V4.1后的新一轮感知中，Rerun的Book segmentation、Spine + center、Aligned depth视图均显示金色上沿中心和掩膜上端短线，标签为`Upper edge | base Z=... mm`。3D场景显示同一个控制上沿点，青色点为名义手指上方110mm/下降后名义上方60mm参考，金色竖线表示上方间距；这些参考不是TCP目标本身。每轮由原Rerun清理流程清除旧标记。未成功取得本轮上沿坐标时不会虚构上沿。

粉色标记对应整书有效点的基座X中位数：三维标记为精确中位X参考，深度图标记为距离该中位数最近的实测样本（中位数不一定对应某个真实像素）。中位数降低少量深度离群点的影响，仍依赖正确掩膜，不推断隐藏书背。原抬升400mm/前伸400mm等范围检查保持。


## 复位GRAPH_FAIL诊断

新V4.1在关节规划失败后打印 `V4.1 joint endpoint diagnostics`，分别提供start/goal完整关节SI值、joint_limit_violations、self_collision_pairs和world_collisions。它只补充诊断，不放行失败轨迹。CPU模型几何结果不替代GPU完整约束；两端均通过时还需检查GPU的边界余量及其他可行性条件。更新后需重启V4.1后端加载指纹。

前伸日志 `V4.1 前伸计算` 分别打印书X中位数、伸入量、指尖X投影、TCP终点和位移。例：书X=600mm、指尖X偏移=50mm、当前TCP X=410mm，伸入100mm时终点650mm、前伸240mm。粉色中位数标记仍代表书的深度参考，实际TCP目标由原执行器预览显示。V3.4共享抓取配置的100mm伸入量不变。


## 远处书自动交给GPT重选

V4.1保留SAM3初选。在整书实测深度得到之后、写入本轮控制几何之前，按当前右TCP和指尖偏移检查：Y对齐位移不超过350mm、X前伸不超过400mm，且前伸目标不在当前TCP后方。数值来自主配置的原行程上限，前伸仍包含热加载伸入量。

超范围时本轮最多调用一次GPT-6重选近处书。模型收到被拒目标框、超范围原因与实测RGB-D生成的粗搜索框，明确允许换书，优先前景推车内可见书脊；不沿用倾角复核的“必须同一本书”约束。搜索框只是候选范围，不代表IK可达或无碰撞。GPT输出图像区域后，以本帧真实深度重新计算书中心和整书基座X中位数，并用模型等待结束后的当前TCP再次检查。仍超范围、无可靠区域或无有效深度时保留失败，不扩大行程或继续追远处目标。没有可搜索实测深度区域时也不调用模型。

日志包括`V4.1 选书超出粗定位距离，交给 GPT-6 重选近处书`与`V4.1 GPT 近处选书通过距离检查`。请求/结果沿用`RobotRAM/output/v32_head_gpt_*/result.json`记录（distance重选上下文仍存于历史字段tilt_review）；选中几何携带distance_reselection前后距离。该钩子仅由当前V4.1安装，V3.4保持原默认选书方式。首次需重启抓取程序加载此代码；不用重启规划器。
