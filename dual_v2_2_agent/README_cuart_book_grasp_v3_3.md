启动入口 `cuart_book_grasp_v3_3.py`，沿用 V3.2 伺服配置与 GPT-6 备用分割，仅切换本机头部相机输入。V3.2 的默认输入仍为 848×530。

共享相机按 SDK 枚举的最大彩色像素面积选择支持的原始 RGB/MJPG/BGR profile（当前 Gemini 305 为 1280×800），保留同帧 D2C 深度；不会把缩略图放大。必须 RGB 与对齐深度尺寸一致，否则停止发布该帧。共享协议额外传输原始 RGB-D，AR 和旧客户端仍收到原来的标定尺寸版本。V3.3 使用原始 RGB-D，内参通过 cv2.resize 像素中心关系换算；R/T、畸变参数和毫米深度单位保持不变。掩码、深度、内参在同一分辨率计算，不使用新旧帧拼接。

SAM3、GPT-6 和 SAM2 都接收该原始输入，网络内部编码尺寸仍由模型决定。GPT 仅在 SAM3 找不到可靠书脊时触发，自动读取现有密钥文件；所有几何和深度检查继续执行。

## 腕部透视边界备用（2026-10-12）

取消两侧方向差大于 5° 就拒绝的硬门槛。语义书脊掩码和图像边界备用共用宽度检查：整个观测区间不得交叉/小于 8 px，拟合两端宽度比不超过 1.8，宽度变化不超过中位宽度的 60%，宽度线性拟合残差 P90 不超过 max(3 px, 8% 中位宽度)。允许向上/向下收窄或展开。

图像边界备用另外在共同观测区间重新检验真实 Canny 边缘：±3 px 内支持率 ≥85%，最长无支持间隙 ≤max(10 px, 6% 区间长度)，边界两侧亮度阶跃同向支持率 ≥75%，避免将文字笔画或合并后的大间隙当成书边。近中央多组候选歧义检测保留。逐对失败原因写入 `wrist_detection.json` 的 `rejected_pairs`。
