## 预算边界与前伸恢复修正

- 仅 V3.4 启用前伸策略：视觉连续控制 gain 从 0.6 降到 **0.35**，实际加载 `cart_book_grasp_v3_4_stream.json`；column 文件的 gain 是旧控制接口参数，不用于该连续视觉循环。
- X 前伸目标最大领先实测 TCP **20 mm**。Y/Z/角度误差达到各自恢复阈值的 50% 后，前伸目标距离线性收短；达到阈值时降为零，仍继续纠偏。视觉模式另外依据图像误差接近原有前伸/对准切换边界时收短目标。该策略改变目标距离，不改变适配器 50 Hz 周期或速度硬限。

## 边界算法

1. SAM3 的 book / book spine 候选仍优先；备用由 `cart_book_grasp_v3_4_edges.py` 实现。LSD 提取竖向短线段，最低长度 max(12 px, 3.5% 图高)，而非要求单根长线达到图高的 25%。
2. 按端点到拟合线距离 ≤4 px、斜率差 ≤0.12、段间间隙 ≤16% 图高连接，Huber 拟合两侧直线。这些只是候选假设，连接并不自动意味着边界有效。
3. 对整个共同观测区间回查原始像素：灰度与 Lab 色度通道共同提供边缘证据。亮度相近、颜色不同的书脊/背景仍可识别。要求 ±3 px 边缘支持率 ≥85%，最长无支持间隙 ≤max(10 px, 6% 区间长度)。大缺口不能凭线段连接直接补成可靠边界。
4. 在边界两侧 4–9 px、10–16 px 两个距离范围，要求同一 Lab 通道的颜色阶跃方向持续一致，支持率 ≥75%。文字细笔画两边通常都是书脊底色，不能只凭局部梯度强就通过。算法没有硬编码浅色、棕色或某本书的像素位置。
5. 继续使用已有透视宽度限制、共同纵向长度和中心行覆盖要求。多组近中央候选或共享边界的相邻带均拒绝，防止把两本书之间的间隙选为书脊。宽度比不能单独消除这种歧义。
6. 中线来自两条外边界之间的掩码。内部特征点只负责后续跟踪，不用点的平均坐标定义中线。沿用已有内部采点区域和至少 6 点初始化要求。

结果与每对候选淘汰原因写入原输出目录的 `wrist_detection.json`。新备用的 method 为 `joined_color_boundaries_v3_4`。这是几何备用，不宣称验证了书本语义身份。不会在单边缺失或候选歧义时强制前伸。
